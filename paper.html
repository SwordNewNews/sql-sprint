答案与判分点

卷 A

1. 查 11 月订单（10 分） 
SELECT OrderNo, Amount, OrderDate
FROM Orders
WHERE OrderDate >= '2026-11-01' AND OrderDate < '2026-12-01'
ORDER BY OrderDate DESC;
判分：日期区间 5 分（用 BETWEEN 也给分）、排序 3 分、字段 2 分。
2. 金额最高的前 10 笔（10 分） 
SELECT TOP 10 OrderNo, Amount
FROM Orders
ORDER BY Amount DESC;
判分：TOP 10 5 分、ORDER BY … DESC 5 分。TOP 和 ORDER BY 必须同时出现，否则「前 10」没有意义。
3. 订单 + 客户名（12 分） 
SELECT o.OrderNo, c.CustomerName, o.Amount
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId;
判分：别名 4 分、ON c.Id = o.CustomerId 5 分、字段 3 分。
4. 所有客户 + 订单数（0 也要显示）（15 分） 
SELECT c.CustomerName, COUNT(o.Id) AS 订单数
FROM Customer c
LEFT JOIN Orders o ON o.CustomerId = c.Id
GROUP BY c.CustomerName;
判分：LEFT JOIN 7 分（写成 JOIN 最多给 3 分）、COUNT(o.Id) 5 分（写 COUNT(*) 会显示 1，扣 3 分）、GROUP BY 3 分。
5. 按客户统计并筛总金额（15 分） 
SELECT c.CustomerName, COUNT(o.Id) AS 下单次数, SUM(o.Amount) AS 总金额
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE o.OrderDate >= '2026-01-01' AND o.OrderDate < '2027-01-01'
GROUP BY c.CustomerName
HAVING SUM(o.Amount) > 10000
ORDER BY SUM(o.Amount) DESC;
判分：分组 4 分、时间条件 3 分、HAVING 4 分（写进 WHERE 直接 0 分）、排序 2 分、聚合 2 分。
6. 新增客户（10 分） 
INSERT INTO Customer (CustomerName, Phone, Status, CreateTime)
VALUES (N'丁公司', '13900000004', 1, GETDATE());
判分：INSERT INTO … VALUES 结构 6 分、字段与值一一对应 2 分、GETDATE() 2 分。
7. 关联更新订单金额（14 分） 
UPDATE o
SET o.Amount = o.Qty * p.Price
FROM Orders o
JOIN Product p ON p.Id = o.ProductId
WHERE o.Status = 0;
判分：UPDATE 别名 4 分、FROM … JOIN … ON … 6 分、SET 表达式 4 分。这是 SQL Server 的标志写法。
8. 关联删除订单（14 分） 
DELETE o
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE c.Status = 9;
判分：DELETE 别名 5 分、关联条件 5 分、WHERE c.Status = 9 4 分。

卷 B

1. 按月统计 6–9 月（15 分） 
SELECT MONTH(OrderDate) AS 月份, SUM(Amount) AS 金额合计
FROM Orders
WHERE OrderDate >= '2026-06-01' AND OrderDate < '2026-10-01'
GROUP BY MONTH(OrderDate)
ORDER BY MONTH(OrderDate);
判分：MONTH() 4 分、范围条件 4 分、GROUP BY MONTH(OrderDate) 5 分、排序 2 分。
2. 行转列：客户 × 月份（20 分） 
SELECT c.CustomerName,
  SUM(CASE WHEN MONTH(o.OrderDate) = 1  THEN o.Amount ELSE 0 END) AS M1,
  SUM(CASE WHEN MONTH(o.OrderDate) = 2  THEN o.Amount ELSE 0 END) AS M2,
  -- …… 3 到 11 月同样写法 ……
  SUM(CASE WHEN MONTH(o.OrderDate) = 12 THEN o.Amount ELSE 0 END) AS M12
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE YEAR(o.OrderDate) = 2026
GROUP BY c.CustomerName;
判分：SUM(CASE WHEN …) 结构 10 分、12 列齐全 6 分、分组 4 分。写不完 12 列就写 3 列 + 注「其余同理」，按 12 分给。
3. 每个客户金额最高的一单（20 分） 
SELECT t.CustomerName, t.OrderNo, t.Amount FROM (
  SELECT c.CustomerName, o.OrderNo, o.Amount,
         ROW_NUMBER() OVER (PARTITION BY o.CustomerId ORDER BY o.Amount DESC) AS rn
  FROM Orders o
  JOIN Customer c ON c.Id = o.CustomerId
) t
WHERE t.rn = 1;
判分：ROW_NUMBER() OVER (PARTITION BY … ORDER BY …) 10 分、外层筛选 rn = 1 6 分、关联 4 分。用子查询取 MAX(Amount) 也对，按 16 分给。
4. 套打单张出库单（20 分） 
SELECT m.BillNo, m.BillDate, m.CustomerName,
       d.LineNo, d.ProductName, d.Qty
FROM BillMaster m
LEFT JOIN BillDetail d ON d.BillId = m.Id
WHERE m.BillNo = 'CK20261126001'
ORDER BY d.LineNo;
判分：LEFT JOIN 8 分（写 JOIN 给 5 分，单张单据通常有明细）、条件 6 分、字段 4 分、排序 2 分。
5. 所有出库单（含无明细）（15 分） 
SELECT m.BillNo, m.BillDate, m.CustomerName,
       d.LineNo, d.ProductName, d.Qty
FROM BillMaster m
LEFT JOIN BillDetail d ON d.BillId = m.Id
WHERE m.BillType = N'出库'
ORDER BY m.BillNo, d.LineNo;
判分：LEFT JOIN 9 分（写成 JOIN 只给 2 分，这是本题唯一考点）、类型条件 4 分、排序 2 分。
6. 明细拼成一行（10 分） 
SELECT m.BillNo,
       STUFF((SELECT ',' + d.ProductName
              FROM BillDetail d
              WHERE d.BillId = m.Id
              ORDER BY d.LineNo
              FOR XML PATH(''), TYPE).value('.', 'NVARCHAR(MAX)'), 1, 1, '') AS 明细
FROM BillMaster m;
判分：子查询关联 4 分、+ ',' 拼串 3 分、STUFF 去掉首个逗号 3 分。写不出整串就写前两部分。
