第 0 课：先用 30 秒看懂「表」

这一课不讲 SQL，只建立画面感。没有画面感，后面全是天书。

把数据库想成一个 Excel 文件

一个数据库 = 一个 Excel 文件；文件里的每个工作表 = 一张表；表的每一行 = 一条记录（一笔业务）；每一列 = 一个字段（一种属性）。

比如 ERP 里一定有的两张表：

Customer（客户表）

3丙公司13800000003

Orders（订单表）

IdCustomerIdOrderNoAmountOrderDate

关键：Orders.CustomerId 就是 Customer.Id 订单表里不存客户名字，只存客户的编号。
这就是「关系」。以后所有多表查询，本质都是拿这个编号去客户表里把名字「对」回来。
一句话记住今天要干的四件事 提问（查询）、连接（多表）、统计（报表）、修改（增删改）。明天笔试就考这四件。

第 1 课：只查一张表

目标：从一张表里，挑出你要的列、你要的行、按你要的顺序排。

人话翻译

1
SELECT —— 我要哪几列
2
FROM —— 从哪张表
3
WHERE —— 只要哪些行（可选）
4
ORDER BY —— 怎么排序（可选）
SELECT OrderNo, Amount          -- 要这两列
FROM Orders                     -- 从订单表
WHERE Amount > 1000             -- 只要金额大于 1000 的
ORDER BY Amount DESC;           -- 按金额从大到小

结果：DD003 / 5600、DD001 / 1200。

拆开看每一块

写法含义
SELECT *所有列（考试里可以用，省事）
WHERE Amount >= 1000大于等于；> 大于，< 小于，<> 不等于
WHERE CustomerName = N'甲公司'文本要加单引号，中文前加 N（SQL Server 习惯）
BETWEEN '2026-11-01' AND '2026-11-30'区间，含两端
LIKE N'%甲%'模糊匹配；% 代表任意字符
AND / OR并且 / 或者，OR 记得加括号
ORDER BY Amount DESC倒序；不加 DESC 就是升序 ASC
SELECT TOP 10 …只要前 10 行（SQL Server 特有）
第一个坑：空值 WHERE Amount = NULL 永远查不到东西。空值必须写 WHERE Amount IS NULL。

小测

查出 2026 年 11 月下单、金额大于 2000 的订单号，按日期从新到旧。

看答案 
SELECT OrderNo, Amount, OrderDate
FROM Orders
WHERE OrderDate >= '2026-11-01' AND OrderDate < '2026-12-01'
  AND Amount > 2000
ORDER BY OrderDate DESC;

日期区间用 >= 月初 AND < 下月初 比 BETWEEN 更稳（不会漏掉带时分秒的数据）。

第 2 课：多表连接（明天必考）

目标：把订单表里的「客户编号」换成客户表里的「客户名字」。

为什么需要连接

订单表只存 CustomerId = 1，但报表要显示「甲公司」。名字在另一张表里，所以要把两张表「对起来看」——这就是 JOIN。

你在 Excel 里用 VLOOKUP 干的事，SQL 里就是 JOIN。

两种连接，只要判断一句话

类型什么时候用写法
内连接
INNER JOIN		两边都有数据才算（比如「查订单及其客户名」，没客户的单子不要）JOIN … ON …
左连接
LEFT JOIN		左边一张不能少（比如「查所有客户及其订单」，没下单的客户也要列出来）LEFT JOIN … ON …
SELECT o.OrderNo, c.CustomerName, o.Amount
FROM Orders o                                    -- o 是别名
JOIN Customer c ON c.Id = o.CustomerId           -- 靠这个条件把两张表对起来
ORDER BY o.OrderDate DESC;
三个必须写对的地方 ① 别名（o、c）——两张表都有 Id 时，不写别名就分不清；
② ON 条件——两边的对应关系，写错就是乱连；
③ 字段前带别名（o.Amount）——阅卷一眼看懂。

怎么一眼判断该用 LEFT 还是 INNER

看题目里有没有「所有」「没下过单的」 出现「所有客户」「没有订单的客户」「一张单据要包含空明细」——一律 LEFT JOIN。
只说「查订单和客户名」——用 JOIN 就行。

三张表怎么连

SELECT o.OrderNo, c.CustomerName, p.ProductName, d.Qty
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
JOIN OrderDetail d ON d.OrderId = o.Id
JOIN Product p ON p.Id = d.ProductId;

就是一路 JOIN … ON … 叠下去，每多一张表就多一行。

小测

查出所有客户的名字和他下单的总次数，一次都没下单的客户也要显示（次数为 0）。

看答案 
SELECT c.CustomerName, COUNT(o.Id) AS 订单数
FROM Customer c
LEFT JOIN Orders o ON o.CustomerId = c.Id
GROUP BY c.CustomerName;

注意 COUNT(o.Id) 而不是 COUNT(*)：没下单的客户右表是 NULL，COUNT(列) 不数 NULL，结果才是 0。

第 3 课：分组统计（自定义报表的地基）

目标：从「一行一笔订单」变成「一行一个客户 + 他的合计」。

人话翻译

把行按某一列合并成组，然后对每组算个数、求和、求平均。

口诀：按谁分，就 GROUP BY 谁；要算的数，用聚合函数包起来。

聚合函数含义
COUNT(*) / COUNT(列)数行数（COUNT(列) 不数空值）
SUM(列)求和
AVG(列) / MAX(列) / MIN(列)平均 / 最大 / 最小
SELECT c.CustomerName,
       COUNT(o.Id)   AS 订单数,
       SUM(o.Amount) AS 总金额,
       MAX(o.OrderDate) AS 最近下单
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
GROUP BY c.CustomerName;      -- 按客户名分组

HAVING：给「组」加条件

条件加在哪过滤的是什么
WHERE原始的一行行数据
HAVING分组之后的每组结果
SELECT c.CustomerName, SUM(o.Amount) AS 总金额
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE o.OrderDate >= '2026-01-01'      -- 先在原始行上筛时间
GROUP BY c.CustomerName
HAVING SUM(o.Amount) > 10000           -- 再筛「总金额大于 1 万」的组
ORDER BY SUM(o.Amount) DESC;
第二个坑（扣分最多） SELECT 里出现的列，要么放进 GROUP BY，要么被聚合函数包住。
下面这条是错的：SELECT CustomerName, OrderDate, SUM(Amount) … GROUP BY CustomerName（OrderDate 既没分组也没聚合）。

书写顺序（背下来）

SELECT … FROM … JOIN … ON …
WHERE …
GROUP BY …
HAVING …
ORDER BY …;

小测

按客户统计 2026 年的订单数和总金额，只要总金额超过 1 万的，按总金额倒序。

看答案 
SELECT c.CustomerName, COUNT(o.Id) AS 订单数, SUM(o.Amount) AS 总金额
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE o.OrderDate >= '2026-01-01' AND o.OrderDate < '2027-01-01'
GROUP BY c.CustomerName
HAVING SUM(o.Amount) > 10000
ORDER BY SUM(o.Amount) DESC;

第 4 课：增、删、改

ERP 实施每天都在干的三件事。笔试常考「关联更新」和「事务」。

增：INSERT

-- 插一行
INSERT INTO Customer (CustomerName, Phone, CreateTime)
VALUES (N'丁公司', '13900000004', GETDATE());

-- 把查询结果批量插进去（结转、日志、汇总表常用）
INSERT INTO OrderLog (OrderId, Action, CreateTime)
SELECT o.Id, N'结转', GETDATE()
FROM Orders o
WHERE o.Status = 1;

改：UPDATE

-- 普通更新
UPDATE Orders
SET Status = 2, UpdateTime = GETDATE()
WHERE Id = 101;

-- ★ 关联更新（ERP 必考，SQL Server 专有写法）
UPDATE o
SET o.Amount = o.Qty * p.Price
FROM Orders o
JOIN Product p ON p.Id = o.ProductId
WHERE o.Status = 0;
记住这个形状 UPDATE 别名 SET 别名.列 = … FROM 表 别名 JOIN 另一张表 ON … WHERE …
别名写在 UPDATE 后面，表在 FROM 里连起来——这是 T-SQL 的招牌写法。

删：DELETE

DELETE FROM Orders WHERE Id = 101;

-- 关联删除：删掉「已停用客户」的所有订单
DELETE o
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE c.Status = 9;
永远先写 WHERE DELETE FROM Orders; 会清空整张表。手写时先把 WHERE 写上，再补前面的语句。

事务：要么全成功，要么全不做

BEGIN TRAN;
UPDATE Account SET Balance = Balance - 100 WHERE Id = 1;
UPDATE Account SET Balance = Balance + 100 WHERE Id = 2;
COMMIT TRAN;
-- 中途出错：ROLLBACK TRAN;

三个关键词 BEGIN TRAN / COMMIT / ROLLBACK 写出来就是得分点。能补一句「保证转账不出现只扣不加」更好。

小测

把「电子」分类产品的单价上调 5%，并记录修改时间。

看答案 
UPDATE Product
SET Price = Price * 1.05, UpdateTime = GETDATE()
WHERE Category = N'电子';

第 5 课：报表进阶四招

这四招覆盖「自定义报表」里绝大多数怪题。

第 1 招：分段统计（CASE WHEN）

题目问「小额、中额、大额各多少单」——不是分组，而是按条件数数。

SELECT
  SUM(CASE WHEN Amount < 1000 THEN 1 ELSE 0 END) AS 小额,
  SUM(CASE WHEN Amount >= 1000 AND Amount < 5000 THEN 1 ELSE 0 END) AS 中额,
  SUM(CASE WHEN Amount >= 5000 THEN 1 ELSE 0 END) AS 大额
FROM Orders;

套路：SUM(CASE WHEN 条件 THEN 1 ELSE 0 END) = 「满足条件的行数」。

第 2 招：子查询 / EXISTS（存在、不存在）

题目出现「没有…的」「不存在…的」「有的」——用 EXISTS / NOT EXISTS。

-- 没下过单的客户
SELECT * FROM Customer c
WHERE NOT EXISTS (SELECT 1 FROM Orders o WHERE o.CustomerId = c.Id);

第 3 招：每组取第一条（ROW_NUMBER）

题目问「每个客户金额最高的那一单」「每个产品最新的一次入库」。

SELECT * FROM (
  SELECT o.*, ROW_NUMBER() OVER (PARTITION BY o.CustomerId ORDER BY o.Amount DESC) AS rn
  FROM Orders o
) t
WHERE t.rn = 1;

记法：PARTITION BY = 按谁分组，ORDER BY = 组里怎么排，外面套一层取 rn = 1。

第 4 招：行转列（月份转 12 列）

SELECT CustomerId,
  SUM(CASE WHEN MONTH(OrderDate) = 1  THEN Amount ELSE 0 END) AS M1,
  SUM(CASE WHEN MONTH(OrderDate) = 2  THEN Amount ELSE 0 END) AS M2,
  -- ……
  SUM(CASE WHEN MONTH(OrderDate) = 12 THEN Amount ELSE 0 END) AS M12
FROM Orders
WHERE YEAR(OrderDate) = 2026
GROUP BY CustomerId;

写不完 12 列就写 3 列 + 一句「其余月份同理」，比空着强。

小测

查出每个客户金额最高的那一笔订单（只显示客户名、订单号、金额）。

看答案 
SELECT t.CustomerName, t.OrderNo, t.Amount FROM (
  SELECT c.CustomerName, o.OrderNo, o.Amount,
         ROW_NUMBER() OVER (PARTITION BY o.CustomerId ORDER BY o.Amount DESC) AS rn
  FROM Orders o JOIN Customer c ON c.Id = o.CustomerId
) t
WHERE t.rn = 1;

第 6 课：套打取数

套打 = 把数据填进预印好的单据纸（出库单、发票、凭证）。考的是一次取全主表和明细。

一张单据 = 1 行表头 + N 行明细

单据主表（BillMaster）存单号、日期、客户；明细表（BillDetail）存每一行商品。它们靠 BillId 关联。

SELECT m.BillNo, m.BillDate, m.CustomerName,
       d.LineNo, d.ProductName, d.Qty, d.Amount
FROM BillMaster m
LEFT JOIN BillDetail d ON d.BillId = m.Id
WHERE m.BillNo = 'CK20261126001'
ORDER BY d.LineNo;
为什么必须 LEFT JOIN（判分点） 没有明细的单据也要打出来（留空白行）。用 JOIN 会把这类单据整张丢掉。

表头合计

SELECT m.BillNo, m.CustomerName,
       COUNT(d.Id)   AS 行数,
       SUM(d.Qty)    AS 总数量,
       SUM(d.Amount) AS 总金额
FROM BillMaster m
LEFT JOIN BillDetail d ON d.BillId = m.Id
WHERE m.BillDate >= '2026-11-01' AND m.BillDate < '2026-12-01'
GROUP BY m.BillNo, m.CustomerName
ORDER BY m.BillNo;

把多行明细拼成一行（拉开差距的一招）

有些套打模板要求「一张单据一行，明细用逗号连起来」。SQL Server 的写法是 STUFF + FOR XML PATH。

SELECT m.BillNo,
       STUFF((
         SELECT ',' + d.ProductName + '×' + CAST(d.Qty AS VARCHAR(10))
         FROM BillDetail d
         WHERE d.BillId = m.Id
         ORDER BY d.LineNo
         FOR XML PATH(''), TYPE
       ).value('.', 'NVARCHAR(MAX)'), 1, 1, '') AS 明细
FROM BillMaster m;

结构固定：STUFF((拼接子查询 FOR XML PATH('')),1,1,'')。记不全就写 + ',' 那段拼串，也有分。

小测

查出所有出库单（含没有明细的），显示单号、日期、客户、明细行号、商品名、数量。

看答案 
SELECT m.BillNo, m.BillDate, m.CustomerName,
       d.LineNo, d.ProductName, d.Qty
FROM BillMaster m
LEFT JOIN BillDetail d ON d.BillId = m.Id
WHERE m.BillType = N'出库'
ORDER BY m.BillNo, d.LineNo;

第 7 课：手写怎么拿分

同样的知识，写得让阅卷看得懂 = 多拿 20 分。

落笔顺序（照这个写，不会乱）

1
先写 FROM + 所有 JOIN … ON …（把表连对，这步占一半分）
2
补 WHERE（筛选条件）
3
有聚合就写 GROUP BY、必要时 HAVING
4
回头写 SELECT 的列（含聚合、别名）
5
最后 ORDER BY

格式分（白送的分）

  • 每个子句换行，关键字全大写；
  • 每张表都起别名，字段前带前缀；
  • 每个字段用 AS 中文名 起个中文别名，阅卷一眼看懂；
  • 多表条件写成 JOIN … ON …，不要全塞在 WHERE 里（老写法不扣分，但可读性差）。

不会写的时候（救命三招）

① 写思路注释 -- 思路：先按客户分组求合计，再筛出大于 1 万的
② 写骨架 哪怕聚合写不全，SELECT … FROM … GROUP BY … HAVING … 的框架对了就给分
③ 用笨办法 不会窗口函数就用子查询；不会 FORMAT() 就用 CONVERT()；能跑通优先于漂亮

交卷前 60 秒检查清单

检查项为什么
空值是不是写成 IS NULL= NULL 永远查不到
聚合条件是不是在 HAVING放 WHERE 直接报错
SELECT 的列是否都在 GROUP BY 或被聚合最常见的错
该 LEFT 的地方有没有写成 INNER「所有」「没有的」类题目
括号 / 引号 / END / 分号是否成套手写最容易漏
中文字符串有没有 N'…'SQL Server 中文防乱码

第 8 课：模拟卷（8 题 · 100 分）

先自己写在纸上，再点开答案对。分数 = 成绩，别自欺欺人。

表结构

表字段
Customer 客户Id, CustomerName, Phone, Status
Orders 订单Id, CustomerId, OrderNo, Amount, OrderDate, Status
OrderDetail 订单明细Id, OrderId, ProductId, Qty, Price, Amount
Product 产品Id, ProductName, Category, Price, Stock
BillMaster 单据主表Id, BillNo, BillType, BillDate, CustomerName, TotalAmount

1.（10 分）查询 2026 年 11 月 1 日之后、金额大于 2000 的订单号与金额，按金额从高到低。

答案 + 判分点 
SELECT OrderNo, Amount
FROM Orders
WHERE OrderDate >= '2026-11-01' AND Amount > 2000
ORDER BY Amount DESC;

判分：日期条件 4 分、金额条件 3 分、排序 3 分。

2.（12 分）查询每个客户的名字和订单数，没下过单的客户也要显示 0。

答案 + 判分点 
SELECT c.CustomerName, COUNT(o.Id) AS 订单数
FROM Customer c
LEFT JOIN Orders o ON o.CustomerId = c.Id
GROUP BY c.CustomerName;

判分：LEFT JOIN 6 分、COUNT(o.Id) 3 分、GROUP BY 3 分。

3.（12 分）统计 2026 年每个客户的总金额，只保留超过 1 万的，按总金额倒序。

答案 + 判分点 
SELECT c.CustomerName, SUM(o.Amount) AS 总金额
FROM Orders o
JOIN Customer c ON c.Id = o.CustomerId
WHERE o.OrderDate >= '2026-01-01' AND o.OrderDate < '2027-01-01'
GROUP BY c.CustomerName
HAVING SUM(o.Amount) > 10000
ORDER BY SUM(o.Amount) DESC;

判分：分组 4 分、WHERE 时间 3 分、HAVING 3 分、排序 2 分。

4.（12 分）查出每个客户金额最高的那一笔订单（客户名、订单号、金额）。

答案 + 判分点 
SELECT t.CustomerName, t.OrderNo, t.Amount FROM (
  SELECT c.CustomerName, o.OrderNo, o.Amount,
         ROW_NUMBER() OVER (PARTITION BY o.CustomerId ORDER BY o.Amount DESC) AS rn
  FROM Orders o JOIN Customer c ON c.Id = o.CustomerId
) t
WHERE t.rn = 1;

判分：窗口函数 6 分、外层筛选 4 分、关联 2 分。用子查询求 max 也行。

5.（12 分）把「电子」分类的产品单价上调 5%，并更新修改时间。

答案 + 判分点 
UPDATE Product
SET Price = Price * 1.05, UpdateTime = GETDATE()
WHERE Category = N'电子';

判分：SET 表达式 6 分、WHERE 条件 4 分、时间 2 分。

6.（12 分）用明细表把每张单据的商品名拼成一行（逗号分隔）。

答案 + 判分点 
SELECT m.BillNo,
       STUFF((SELECT ',' + d.ProductName
              FROM BillDetail d
              WHERE d.BillId = m.Id
              ORDER BY d.LineNo
              FOR XML PATH(''), TYPE).value('.', 'NVARCHAR(MAX)'), 1, 1, '') AS 商品清单
FROM BillMaster m;

判分：子查询关联 5 分、STUFF/FOR XML 结构 5 分、去掉首个逗号 2 分。

7.（15 分）查询所有出库单（含无明细的）的单号、日期、客户、明细行号、商品、数量。

答案 + 判分点 
SELECT m.BillNo, m.BillDate, m.CustomerName,
       d.LineNo, d.ProductName, d.Qty
FROM BillMaster m
LEFT JOIN BillDetail d ON d.BillId = m.Id
WHERE m.BillType = N'出库'
ORDER BY m.BillNo, d.LineNo;

判分：LEFT JOIN 8 分（写成 INNER 只给 2 分）、类型条件 4 分、排序 3 分。

8.（15 分）写一个转账事务：账户 1 扣 100 给账户 2，要求要么都成功要么都不生效。

答案 + 判分点 
BEGIN TRAN;
UPDATE Account SET Balance = Balance - 100 WHERE Id = 1;
UPDATE Account SET Balance = Balance + 100 WHERE Id = 2;
COMMIT TRAN;

判分：BEGIN/COMMIT 6 分、两条更新各 3 分、能说明异常时 ROLLBACK 3 分。
